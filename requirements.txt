# ─── Voice Chat Streaming ─────────────────────────────────────────────────────
# IMPORTANT: the PyPI package is "py-tgcalls", NOT "pytgcalls".
# "pytgcalls" (no dash) is the old abandoned package that depends on the
# broken tgcalls C++ extension and causes ResolutionImpossible on Python 3.12.
# "py-tgcalls" is the current maintained package; it uses ntgcalls which ships
# pre-built binaries for Linux x86_64 — zero C++ compilation required.
# Both packages expose the same import name: `from pytgcalls import PyTgCalls`.
py-tgcalls>=2.0.0

# ntgcalls is pulled in automatically by py-tgcalls, but pinning it explicitly
# ensures pip picks a wheel-only release (no source build on Render).
